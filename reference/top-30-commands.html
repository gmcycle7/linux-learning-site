If You Only Remember 30 Commands, Remember These

These are the 30 most essential Linux commands for a beginner, ranked by how often you will use them and how critical they are to daily work. Master these and you can handle the vast majority of tasks on any Linux system.

How to use this list

Start from the top and work down. The first 10 commands are ones you will use in literally every terminal session. The next 10 come up multiple times a day. The final 10 round out your essential toolkit.

1. cd — Change Directory

Navigate to any location on the filesystem. This is the first command you will type in almost every session.

Key flags: ~ (home), - (previous directory), .. (parent directory)

$ cd /var/log         # go to an absolute path
$ cd ..               # go up one level
$ cd ~                # go to your home directory
$ cd -                # go back to previous directory

Why top 30: You cannot do anything useful without moving around the filesystem. This is the most fundamental navigation command.

2. ls — List Directory Contents

See what files and folders exist in a directory. You will pair this with cd constantly.

Key flags: -l (long format), -a (show hidden), -h (human-readable sizes), -t (sort by time)

$ ls -lah
drwxr-xr-x  5 alex alex 4.0K Mar 15 10:00 .
drwxr-xr-x 20 alex alex 4.0K Mar 15 09:30 ..
-rw-r--r--  1 alex alex  12K Mar 15 10:00 notes.txt
drwxr-xr-x  3 alex alex 4.0K Mar 14 14:22 projects

Why top 30: You need to see what is around you before you can act on it. ls -la is probably the single most typed command sequence on Linux.

3. pwd — Print Working Directory

Show exactly where you are in the filesystem right now.

Key flags: -P (resolve symlinks to show the physical path)

$ pwd
/home/alex/projects/webapp

Why top 30: When you get lost (and you will), pwd is your GPS. It is fast, simple, and always works.

4. cat — Print File Contents

Quickly display the entire contents of a file. Best for short files.

Key flags: -n (number lines), -b (number non-blank lines)

$ cat /etc/hostname
webserver01

Why top 30: Viewing file contents is the most common reason you open a terminal. cat is the fastest way to peek at a configuration file, a script, or a log snippet.

5. grep — Search for Text Patterns

Find specific text inside files or command output. Indispensable for logs, config files, and data analysis.

Key flags: -i (ignore case), -r (recursive), -n (line numbers), -v (invert match), -c (count)

$ grep -rn "ERROR" /var/log/app/
/var/log/app/server.log:142:2024-03-15 ERROR: Connection refused
/var/log/app/server.log:289:2024-03-15 ERROR: Timeout exceeded

Why top 30: Searching for text is one of the most powerful things you can do on the command line. grep replaces Ctrl+F for entire directory trees of files.

6. sudo — Run as Superuser

Execute a command with root (administrator) privileges. Required for system administration tasks.

Key flags: -i (open a root shell), -u user (run as another user)

$ sudo apt update
$ sudo systemctl restart nginx

Why top 30: Any time you install software, edit system files, or manage services, you need sudo. It is the gatekeeper to administrative power.

7. cp — Copy Files and Directories

Duplicate files or entire directory trees.

Key flags: -r (recursive, for directories), -i (ask before overwriting), -v (verbose)

$ cp config.yaml config.yaml.bak
$ cp -r project/ project-backup/

Why top 30: Making backups before editing is the most important safety habit in Linux. cp is how you do it.

8. mv — Move or Rename

Move files to a new location or rename them. Works for both files and directories.

Key flags: -i (ask before overwriting), -v (verbose)

$ mv report.txt final-report.txt        # rename
$ mv downloads/*.pdf ~/documents/       # move

Why top 30: Renaming and organizing files is a daily activity. mv handles both in one command.

9. rm — Remove Files

Delete files and directories. There is no trash can on the command line, so be careful.

Key flags: -r (recursive, for directories), -i (ask before each deletion), -v (verbose)

$ rm temp.log
$ rm -ri old-project/     # ask before deleting each file
Warning

Never run rm -rf / or rm -rf ~. Always double-check your path before pressing Enter. Use -i when in doubt.

Why top 30: Cleaning up files is essential for keeping a system organized and freeing disk space.

10. mkdir — Create Directories

Create new directories (folders).

Key flags: -p (create parent directories as needed), -v (verbose)

$ mkdir -p projects/webapp/src/components

Why top 30: Organizing files into directories is the foundation of a clean system. The -p flag saves you from creating each level one at a time.

11. less — Page Through Files

View large files one screen at a time, with scrolling and searching.

Key flags: -N (line numbers), -S (chop long lines). Inside less: / to search, n next match, q quit.

$ less -N /var/log/syslog

Why top 30: cat floods the screen with large files. less lets you read them comfortably with searching and navigation.

12. man — Read the Manual

Display the manual page for any command. This is your built-in documentation system.

Key flags: -k keyword (search all man pages by keyword)

$ man grep
$ man -k "copy files"

Why top 30: You cannot memorize every flag for every command. man is how you learn on the fly. The best Linux users are the ones who read man pages.

13. find — Search for Files

Locate files by name, type, size, modification time, and many other criteria.

Key flags: -name (by name), -type f/d (file or directory), -size (by size), -mtime (by modification time), -exec (run a command on results)

$ find /home -name "*.log" -size +50M -mtime +30
# Find .log files over 50MB that haven't been modified in 30 days

Why top 30: On a real system with thousands of files, you need a way to find things. find is the most powerful file-searching tool on Linux.

14. chmod — Change Permissions

Control who can read, write, and execute a file.

Key flags: -R (recursive), numeric mode (755, 644) or symbolic mode (u+x, go-w)

$ chmod +x deploy.sh         # make a script executable
$ chmod 644 config.yaml      # owner read/write, others read only

Why top 30: You will run into "Permission denied" errors regularly. chmod is how you fix them. Understanding permissions is essential for security.

15. tail — View End of File

Show the last lines of a file. With -f, it follows a file in real time.

Key flags: -n N (show N lines), -f (follow live updates)

$ tail -f /var/log/nginx/access.log
# Watch requests hit your web server in real time. Ctrl+C to stop.

Why top 30: tail -f is the single most important debugging tool for servers. When something goes wrong, the first thing you do is watch the logs.

16. echo — Print Text

Display a line of text, a variable's value, or output to a file.

Key flags: -n (no trailing newline), -e (enable escape sequences)

$ echo "Hello, $USER"
Hello, alex
$ echo $PATH

Why top 30: Essential for debugging scripts, checking variable values, and generating output. It is the print statement of the shell.

17. touch — Create Empty Files

Create a new empty file, or update the timestamp of an existing file.

Key flags: -t (set a specific timestamp)

$ touch index.html style.css app.js

Why top 30: The quickest way to create files. Often paired with mkdir -p to set up project structures.

18. ps — View Running Processes

Show a snapshot of all running processes.

Key flags: aux (all users, detailed), -ef (full format), --forest (tree view)

$ ps aux | grep nginx
root   1234  0.0  0.1  12345  6789 ?  Ss  10:00  0:00 nginx: master
www    1235  0.0  0.2  12345  9876 ?  S   10:00  0:01 nginx: worker

Why top 30: Knowing what is running on your system is crucial for troubleshooting, performance monitoring, and security.

19. kill — Stop a Process

Send a signal to a process to terminate or control it.

Key flags: -9 (SIGKILL, force stop), -15 (SIGTERM, graceful stop, the default)

$ kill 1234       # politely ask process 1234 to stop
$ kill -9 1234   # force-kill it immediately

Why top 30: Programs hang, loops run forever, and services misbehave. kill is how you take control back.

20. df — Check Disk Space

Show how much disk space is used and available on all mounted filesystems.

Key flags: -h (human-readable sizes), -T (show filesystem type)

$ df -h
Filesystem      Size  Used  Avail  Use%  Mounted on
/dev/sda1        50G   32G    16G   67%  /
/dev/sdb1       200G   89G   101G   47%  /data

Why top 30: Running out of disk space is one of the most common causes of server failures. df -h is the first thing to check.

21. du — Check Directory Size

Find out how much space files and directories are using.

Key flags: -h (human-readable), -s (summary, total only), -d N (depth limit)

$ du -sh * | sort -rh | head -5
4.2G    node_modules
1.1G    build
256M    data
45M     src
12M     docs

Why top 30: When df tells you the disk is full, du tells you which directories are the culprits.

22. head — View Start of File

Show the first N lines of a file. The counterpart to tail.

Key flags: -n N (show N lines, default 10)

$ head -n 5 data.csv
id,name,email,department
1,Alice,alice@example.com,engineering
2,Bob,bob@example.com,marketing
3,Carol,carol@example.com,engineering
4,Dave,dave@example.com,sales

Why top 30: Great for peeking at data files, checking CSV headers, or verifying a file's format without loading the whole thing.

23. ssh — Secure Remote Login

Connect to a remote machine securely over the network.

Key flags: -p port (custom port), -i keyfile (identity file)

$ ssh alex@192.168.1.50
$ ssh -i ~/.ssh/deploy_key deploy@production-server.com

Why top 30: If you work with servers, ssh is how you access them. It is the universal remote access tool for Linux machines.

24. tar — Create and Extract Archives

Bundle files into an archive and optionally compress them.

Key flags: -c (create), -x (extract), -z (gzip), -f file (filename), -v (verbose)

$ tar -czf backup-2024-03-15.tar.gz project/    # create
$ tar -xzf backup-2024-03-15.tar.gz              # extract

Why top 30: Backups, deployments, and file transfers almost always involve tar archives. The flags are famously tricky, so memorize -czf (create) and -xzf (extract).

25. history — Command History

Show the list of all commands you have typed previously.

Key flags: -c (clear history). Shortcuts: !! (repeat last command), !N (repeat command N), Ctrl+R (reverse search).

$ history | grep "apt install"
  142  sudo apt install nginx
  287  sudo apt install postgresql
$ !142    # re-run command #142

Why top 30: You will often need to re-run or find a command you typed earlier. Ctrl+R for reverse search is a massive productivity boost.

26. apt — Install Software (Debian/Ubuntu)

The package manager for Debian-based systems. Install, update, and remove software.

Key subcommands: update (refresh package list), upgrade (upgrade packages), install (install a package), remove (remove a package), search (find packages)

$ sudo apt update && sudo apt upgrade -y
$ sudo apt install htop

Why top 30: Installing software is one of the first things you do on a new system. If you use Ubuntu or Debian (the most popular distros), apt is your gateway to all available software.

27. ping — Test Network Connectivity

Send test packets to a host to check if it is reachable over the network.

Key flags: -c N (send N packets and stop)

$ ping -c 4 google.com
PING google.com (142.250.80.46): 56 data bytes
64 bytes from 142.250.80.46: icmp_seq=0 ttl=118 time=12.3 ms
--- google.com ping statistics ---
4 packets transmitted, 4 received, 0% packet loss

Why top 30: The first step in diagnosing any network problem. "Can I reach the server?" is always the first question.

28. curl — Transfer Data from URLs

Fetch data from or send data to a URL. Supports HTTP, HTTPS, FTP, and many other protocols.

Key flags: -O (save with remote filename), -o file (save to specific file), -L (follow redirects), -s (silent), -I (headers only)

$ curl -I https://example.com          # check HTTP headers
$ curl -O https://example.com/file.tar.gz  # download a file

Why top 30: Downloading files, testing APIs, checking web servers, and automating HTTP requests. curl is the Swiss Army knife of the internet.

29. free — Check Memory Usage

Show how much RAM and swap space is used and available.

Key flags: -h (human-readable)

$ free -h
              total   used   free   shared  buff/cache  available
Mem:          16Gi   5.2Gi  3.1Gi   512Mi      7.7Gi     10.1Gi
Swap:          4Gi     0B    4Gi

Why top 30: When a system is slow, memory is one of the first things to check. free -h gives you the answer instantly.

30. chown — Change File Ownership

Change which user and/or group owns a file or directory.

Key flags: -R (recursive), user:group format

$ sudo chown -R www-data:www-data /var/www/html/

Why top 30: File ownership errors are one of the most common causes of "Permission denied" on servers. chown fixes them. It goes hand-in-hand with chmod.
