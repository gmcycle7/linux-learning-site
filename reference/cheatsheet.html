Command Cheat Sheet

A one-page quick reference for the most common Linux commands. Each entry shows the command, a brief description, the most important flags, and a practical example. Print this page or bookmark it for quick access.

Tip

Use man command or command --help to see full documentation for any command listed here.

Navigation

Commands for moving around the filesystem.

CommandDescriptionKey FlagsExample
pwd Print the current working directory (where you are right now). -P resolve symlinks 
$ pwd
/home/alex/projects
ls List files and directories. -l long format, -a show hidden, -h human sizes, -t sort by time, -R recursive 
$ ls -lah /var/log
cd Change directory. - go to previous dir, ~ go home 
$ cd /etc/nginx
$ cd -   # back to previous dir
$ cd ~   # go home

File Operations

Commands for creating, copying, moving, and deleting files and directories.

CommandDescriptionKey FlagsExample
touch Create an empty file or update its timestamp. -t set specific time 
$ touch notes.txt
mkdir Create directories. -p create parent dirs too, -v verbose 
$ mkdir -p projects/app/src
cp Copy files and directories. -r recursive (for dirs), -i ask before overwrite, -v verbose, -p preserve attributes 
$ cp -rv src/ backup/
mv Move or rename files and directories. -i ask before overwrite, -v verbose, -n no overwrite 
$ mv old-name.txt new-name.txt
$ mv file.txt /home/alex/docs/
rm Remove files and directories. -r recursive (for dirs), -f force (no prompt), -i ask first, -v verbose 
$ rm temp.txt
$ rm -ri old-project/
ln Create links (hard or symbolic). -s symbolic link, -f force overwrite 
$ ln -s /usr/bin/python3 /usr/local/bin/python

Viewing Files

Commands for reading file contents without editing.

CommandDescriptionKey FlagsExample
cat Print entire file contents to the terminal. -n number lines, -b number non-blank, -s squeeze blank lines 
$ cat -n config.txt
less View files page by page (scrollable, searchable). -N show line numbers, -S chop long lines, /pattern to search 
$ less -N /var/log/syslog
# Press q to quit, / to search
head Print the first N lines of a file (default 10). -n N show N lines, -c N show N bytes 
$ head -n 20 access.log
tail Print the last N lines of a file (default 10). -n N show N lines, -f follow (live updates), -c N show N bytes 
$ tail -f /var/log/syslog
# Live-follow a log file. Ctrl+C to stop.

Text Processing

Commands for searching, transforming, and analyzing text.

CommandDescriptionKey FlagsExample
grep Search for patterns in files or input. -i ignore case, -r recursive, -n line numbers, -c count, -v invert, -l files only, -E extended regex 
$ grep -rn "ERROR" /var/log/
$ grep -i "timeout" app.log
sort Sort lines of text. -n numeric, -r reverse, -k N sort by column N, -u unique, -h human numeric 
$ sort -nrk2 scores.txt
$ du -sh * | sort -rh
uniq Remove or count adjacent duplicate lines (usually used after sort). -c count occurrences, -d show only duplicates, -u show only unique 
$ sort names.txt | uniq -c | sort -rn
cut Extract columns or fields from each line. -d delimiter, -f N field(s), -c N characters 
$ cut -d: -f1 /etc/passwd
$ echo "hello world" | cut -c1-5
awk Pattern-scanning and text-processing language. Great for columnar data. -F field separator, {print $N} print Nth field 
$ awk -F: '{print $1, $3}' /etc/passwd
$ df -h | awk '{print $1, $5}'
sed Stream editor for find-and-replace and text transformations. -i edit in place, -e multiple expressions, s/old/new/g substitute 
$ sed 's/http/https/g' urls.txt
$ sed -i 's/foo/bar/g' config.conf
tr Translate (replace) or delete characters. -d delete characters, -s squeeze repeats 
$ echo "HELLO" | tr 'A-Z' 'a-z'
hello
$ echo "a::b:::c" | tr -s ':'
a:b:c
wc Count lines, words, and characters. -l lines only, -w words only, -c bytes, -m characters 
$ wc -l access.log
14523 access.log

Search

Commands for finding files and programs on the system.

CommandDescriptionKey FlagsExample
find Search for files and directories by name, type, size, time, and more. -name by name, -type f/d file or dir, -size by size, -mtime by modification time, -exec run command 
$ find /var/log -name "*.log" -size +10M
$ find . -type f -name "*.tmp" -exec rm {} \;
locate Find files quickly using a pre-built database (faster than find). -i ignore case, -c count, -r regex 
$ locate -i "readme.md"
$ sudo updatedb  # refresh the database
which Show the full path of a command (finds it in your PATH). -a show all matches 
$ which python3
/usr/bin/python3

Permissions

Commands for controlling who can read, write, and execute files.

CommandDescriptionKey FlagsExample
chmod Change file permissions (read, write, execute). -R recursive, numeric (755) or symbolic (u+x) 
$ chmod 755 script.sh
$ chmod u+x deploy.sh
$ chmod -R 644 public/
chown Change file owner and/or group. -R recursive, user:group format 
$ sudo chown www-data:www-data /var/www/html
$ sudo chown -R alex ~/project
sudo Run a command as the superuser (root). -i root shell, -u user run as another user, -l list allowed commands 
$ sudo apt update
$ sudo -u postgres psql

Processes

Commands for inspecting and controlling running programs.

CommandDescriptionKey FlagsExample
ps Show a snapshot of running processes. aux all users/detailed, -ef full-format listing, --forest tree view 
$ ps aux | grep nginx
$ ps -ef --forest
top Real-time view of processes, CPU, and memory usage. -d N refresh every N seconds, -u user filter by user. Inside: q quit, k kill, M sort by memory 
$ top
$ top -u alex
kill Send a signal to a process (default: SIGTERM to stop it). -9 force kill (SIGKILL), -15 graceful stop (SIGTERM), -l list signals 
$ kill 1234         # graceful stop
$ kill -9 1234     # force kill
$ killall firefox  # kill by name
bg Resume a stopped job in the background. %N job number 
$ bg %1
fg Bring a background job to the foreground. %N job number 
$ fg %1
jobs List background and stopped jobs in the current shell. -l show PIDs 
$ jobs -l
[1]+  12345 Running   ./server &

System Info

Commands for checking disk space, memory, uptime, and system identity.

CommandDescriptionKey FlagsExample
df Show disk space usage for mounted filesystems. -h human-readable, -T show filesystem type, -i show inodes 
$ df -hT
Filesystem  Type  Size  Used  Avail  Use%  Mounted on
/dev/sda1   ext4   50G   22G    26G   46%  /
du Show disk space used by files and directories. -h human-readable, -s summary, -d N depth, --max-depth=N 
$ du -sh * | sort -rh | head
$ du -hd1 /home
free Show memory (RAM) and swap usage. -h human-readable, -g gigabytes, -s N repeat every N seconds 
$ free -h
              total   used   free  shared  buff/cache  available
Mem:          16Gi   5.2Gi  3.1Gi   512Mi      7.7Gi     10.1Gi
Swap:          4Gi     0B    4Gi
uptime Show how long the system has been running and load averages. -p pretty format, -s since when 
$ uptime
 14:32:01 up 23 days, 4:15,  2 users,  load average: 0.12, 0.08, 0.05
uname Show system information (kernel, architecture). -a all info, -r kernel release, -m architecture 
$ uname -a
Linux server01 5.15.0-56-generic #62 SMP x86_64 GNU/Linux
whoami Print the current username. (no flags) 
$ whoami
alex

Networking

Commands for network testing, file transfers, and remote access.

CommandDescriptionKey FlagsExample
ping Test network connectivity to a host. -c N send N packets, -i N interval in seconds 
$ ping -c 4 google.com
curl Transfer data from or to a URL (HTTP, FTP, and more). -o file save to file, -O use remote filename, -L follow redirects, -s silent, -I headers only 
$ curl -O https://example.com/file.tar.gz
$ curl -sI https://example.com
wget Download files from the web (simpler than curl for downloads). -O file output filename, -q quiet, -c resume, -r recursive 
$ wget -c https://example.com/large-file.iso
ssh Securely connect to a remote machine. -p port custom port, -i key identity file, -L port forwarding 
$ ssh alex@192.168.1.100
$ ssh -p 2222 -i ~/.ssh/mykey user@server.com
scp Copy files between machines over SSH. -r recursive, -P port custom port, -i key identity file 
$ scp file.txt alex@server:/home/alex/
$ scp -r project/ alex@server:~/backups/
rsync Efficiently sync files (copies only changes). -a archive, -v verbose, -z compress, --delete remove extra files, --dry-run preview 
$ rsync -avz ./project/ alex@server:~/project/
$ rsync -avz --dry-run src/ dest/
ip Show and configure network interfaces and routing. addr show IP addresses, link show interfaces, route show routes 
$ ip addr show
$ ip route

Archives & Compression

Commands for creating and extracting compressed files.

CommandDescriptionKey FlagsExample
tar Create or extract archive files (.tar, .tar.gz, .tar.bz2, .tar.xz). -c create, -x extract, -z gzip, -j bzip2, -J xz, -f file filename, -v verbose, -t list contents 
$ tar -czf backup.tar.gz project/
$ tar -xzf backup.tar.gz
$ tar -tf archive.tar.gz   # list only
gzip Compress or decompress files (.gz). -d decompress, -k keep original, -v verbose, -9 best compression 
$ gzip -k large-file.log
$ gzip -d large-file.log.gz
zip Create zip archives (cross-platform compatible). -r recursive, -e encrypt, -9 best compression 
$ zip -r archive.zip folder/
$ unzip archive.zip -d output/
xz High-ratio compression (.xz format). -d decompress, -k keep original, -9 best compression, -v verbose 
$ xz -k database.sql
$ xz -d database.sql.xz

Package Management

Commands for installing, updating, and removing software. The command depends on your Linux distribution.

Debian / Ubuntu (apt)

CommandDescriptionExample
apt update Refresh the list of available packages. 
$ sudo apt update
apt upgrade Upgrade all installed packages to their latest versions. 
$ sudo apt upgrade -y
apt install Install a package. 
$ sudo apt install nginx
apt remove Remove a package (keeps config files). 
$ sudo apt remove nginx
apt search Search for a package by name or description. 
$ apt search image editor
dpkg -i Install a .deb package file directly. 
$ sudo dpkg -i package.deb

Red Hat / Fedora / CentOS (yum / dnf)

CommandDescriptionExample
dnf install Install a package. 
$ sudo dnf install httpd
dnf update Update all packages. 
$ sudo dnf update
dnf remove Remove a package. 
$ sudo dnf remove httpd
dnf search Search for packages. 
$ dnf search text editor
yum install Install a package (older Red Hat systems). 
$ sudo yum install git

Arch Linux (pacman)

CommandDescriptionExample
pacman -S Install a package. 
$ sudo pacman -S vim
pacman -Syu Update all packages and the system. 
$ sudo pacman -Syu
pacman -R Remove a package. 
$ sudo pacman -R vim
pacman -Ss Search for a package. 
$ pacman -Ss editor
